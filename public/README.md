# Static Assets

Place your static assets (images, fonts, icons, etc.) in this folder.

These files will be copied to the `dist/` folder during the build process.

## Examples:

- `public/images/` - Image files
- `public/fonts/` - Custom fonts
- `public/icons/` - Icons and favicons
- `public/favicon.ico` - Site favicon

## Usage in HTML:

```html
<img src="/images/logo.png" alt="Logo">
<link rel="icon" href="/favicon.ico">
```

## Usage in CSS/SCSS:

```css
background-image: url('/images/background.jpg');
```
